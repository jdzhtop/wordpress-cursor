## 第20章：接口开发

### WordPress 7.0 块主题开发简介

WordPress 5.9 引入了完整站点编辑（FSE）功能，WordPress 6.0（2022年5月）进一步稳定了这一功能。块主题使用 HTML 文件定义模板，放置在主题根目录的 `templates` 文件夹中。

**块主题结构：**

```
主题目录/
├── functions.php          # PHP 函数和 REST API 注册
├── templates/            # HTML 模板目录
│   ├── front-page.html   # 首页模板
│   ├── page.html         # 默认页面模板
│   └── calculator.html   # 计算器页面模板
├── style.css             # 主题样式
└── theme.json            # 主题全局配置
```

**块主题与传统主题对比：**

| 对比项 | 传统主题 | 块主题 |
|-------|---------|--------|
| 模板格式 | PHP 文件 | HTML 文件 |
| 模板位置 | 主题根目录 | templates 目录 |
| 编辑方式 | 代码编辑 | 站点编辑器 + 代码 |
| 灵活性 | 高 | 更高 |
| WordPress 版本 | 所有版本 | 5.9+ |

### REST API 工作原理

```
前端页面（浏览器）
    ↓ HTTP 请求（JSON）
WordPress REST API 端点
    ↓
WordPress 主题 functions.php 处理逻辑
    ↓ HTTP 响应（JSON）
前端页面（浏览器）
```

**与传统表单提交的区别：**

| 对比项 | 传统表单提交 | REST API 方式 |
|-------|-------------|---------------|
| 页面刷新 | 需要 | 无需 |
| 数据格式 | URL编码 | JSON |
| 交互体验 | 较差 | 流畅 |
| 跨域支持 | 困难 | 简单 |
| 实时性 | 低 | 高 |

### 第一个接口实例：加法计算器

本节通过一个完整的"加法计算器"实例，演示 WordPress 7.0 块主题的 REST API 开发流程。

#### 需求说明

- 前端：2个数字输入框 + 1个提交按钮
- 后端：接收两个数字，返回它们的和
- 不使用任何额外插件

#### 后端接口开发

**步骤 1：准备块主题**

如果你使用的是块主题（如 WordPress 默认主题 Twenty Twenty-Four），直接进行下一步。如果使用传统主题，建议创建或切换到块主题。

**步骤 2：注册 REST API 路由**

在主题的 `functions.php` 文件中添加以下代码：

```php
/**
 * 注册自定义 REST API 路由
 * WordPress 7.0 块主题版本
 */
add_action('rest_api_init', function() {
    register_rest_route('calculator/v1', '/add', array(
        'methods'  => 'POST',
        'callback' => 'calculator_add_numbers',
        'permission_callback' => '__return_true'
    ));
});

/**
 * 加法计算回调函数
 * @param WP_REST_Request $request 请求对象
 * @return WP_REST_Response|WP_Error
 */
function calculator_add_numbers($request) {
    // 获取请求参数
    $num1 = isset($request['num1']) ? floatval($request['num1']) : 0;
    $num2 = isset($request['num2']) ? floatval($request['num2']) : 0;

    // 计算结果
    $result = $num1 + $num2;

    // 返回 JSON 响应
    return new WP_REST_Response(array(
        'success' => true,
        'num1'    => $num1,
        'num2'    => $num2,
        'result'  => $result,
        'message' => '计算成功'
    ), 200);
}
```

**代码说明：**

| 函数/参数 | 说明 |
|----------|------|
| `rest_api_init` | WordPress 初始化 REST API 的钩子 |
| `register_rest_route()` | 注册新的路由 |
| `calculator/v1` | 命名空间，版本标识 |
| `/add` | 路由路径 |
| `methods` | 支持的 HTTP 方法 |
| `callback` | 处理请求的函数 |
| `permission_callback` | 权限验证，`__return_true` 表示允许所有人访问 |
| `WP_REST_Request` | 请求对象，包含所有传入的参数 |
| `WP_REST_Response` | 响应对象，返回 JSON 数据 |

**步骤 3：测试接口**

保存代码后，接口地址为：

```
http://你的域名/wp-json/calculator/v1/add
```

可以使用以下方式测试：

1. **Postman / Apifox**（推荐，支持 POST）
2. **curl 命令**：

```bash
curl -X POST http://localhost/wp-json/calculator/v1/add \
  -H "Content-Type: application/json" \
  -d '{"num1": 10, "num2": 25}'
```

### 接口开发要点总结

#### REST API 路由注册规范

```php
register_rest_route('命名空间', '/路由路径', array(
    'methods'  => '请求方法',      // GET, POST, PUT, DELETE
    'callback' => '处理函数',       // 返回数据
    'permission_callback' => '权限函数'  // 可选
));
```

#### 请求参数获取方式

| 方法 | 用途 |
|------|------|
| `$request['参数名']` | 获取字符串参数 |
| `floatval($request['参数名'])` | 获取浮点数 |
| `intval($request['参数名'])` | 获取整数 |
| `$request->get_json_params()` | 获取整个 JSON 请求体 |

#### 响应方式

| 类 | 说明 |
|-----|------|
| `WP_REST_Response` | 标准响应对象 |
| `WP_Error` | 错误响应对象 |

```php
// 成功响应
return new WP_REST_Response(array(
    'success' => true,
    'data'    => $result
), 200);

// 错误响应
return new WP_Error('error_code', '错误描述', array(
    'status' => 400
));
```

### 常见问题排查

**1. 接口返回 404**

- 检查 `rest_api_init` 钩子是否正确添加
- 确认路由命名空间和路径正确
- 刷新永久链接：设置 → 固定链接 → 保存

**2. 接口返回 403 或 -1**

- 检查 `permission_callback` 返回值
- 确认用户权限是否足够

**3. 前端请求失败**

- 检查浏览器控制台错误信息
- 确认 WordPress 站点地址配置正确
- 检查是否跨域（后端需设置 CORS 头）

**4. 模板不显示**

- 确认 `templates` 文件夹在主题根目录
- 确认 HTML 文件名正确
- 检查页面是否选择了正确模板
