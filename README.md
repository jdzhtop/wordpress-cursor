## 🚀 快速开始

### 在线阅读（推荐）
直接访问 👉 https://jdzhtop.github.io/wordpress-cursor/

### 本地阅读
```bash
# 克隆仓库到本地
git clone https://github.com/jdzhtop/wordpress-cursor.git

# 进入目录
cd wordpress-cursor

# 使用 Mark Text、Typora 等 Markdown 阅读器打开
# 或使用 VS Code + Markdown Preview 插件阅读
```

### 学习顺序建议
1. **新手用户**：按章节顺序 01 → 14 依次学习
2. **有经验用户**：可根据目录直接跳转感兴趣章节
3. **实战项目**：重点阅读 07、08、13 章
