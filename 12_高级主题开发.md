## 第十二章：高级主题开发

### 原理剖析：WordPress 模板层级

**核心概念：** WordPress 按照特定顺序查找模板文件，优先使用更具体的模板。

**经典主题模板层级流程图：**
```
首页请求
    ↓
front-page.php → home.php → index.php

文章请求
    ↓
single-{post_type}-{slug}.php → single-{post_type}.php → single.php → index.php

页面请求
    ↓
page-{slug}.php → page-{id}.php → page.php → index.php

分类请求
    ↓
category-{slug}.php → category-{id}.php → category.php → archive.php → index.php
```

**块主题模板层级（WordPress 7.0 推荐）：**
```
首页请求
    ↓
templates/front-page.html → templates/home.html → templates/index.html

文章请求
    ↓
templates/single-{post_type}-{slug}.html → templates/single-{post_type}.html → templates/single.html → templates/index.html

页面请求
    ↓
templates/page-{slug}.html → templates/page-{id}.html → templates/page.html → templates/index.html
```

**模板文件说明：**

| 文件 | 用途 | 优先级 |
|-----|-----|-------|
| index.php / index.html | 默认模板 | 最低 |
| single.php / single.html | 文章详情页 | 中等 |
| single-{slug}.php / single-{slug}.html | 指定文章 | 最高 |
| page.php / page.html | 页面 | 中等 |
| archive.php / archive.html | 归档页 | 中等 |

### WordPress 7.0 模板新特性

**1. 可视化修订（Visual Revisions）**

**原理：** WordPress 7.0 引入了全新的可视化修订系统，使用滑块对比两个版本，显示改动摘要和颜色提示。

**使用方法：**
```
1. 编辑文章/页面 → 点击右上角 "修订" 图标
2. 使用滑块浏览历史版本
3. 查看改动摘要：
   - 绿色：新增内容
   - 红色：删除内容
   - 黄色：修改内容
4. 点击 "恢复此版本" 回滚
```

**优势：**
- 直观对比不同版本
- 快速定位修改内容
- 支持区块级修订查看
- 改动摘要一目了然

**2. 区块注释（Notes）**

**原理：** 允许在区块编辑器中添加内联注释，方便团队协作编辑。

**使用方法：**
```
1. 选择区块 → 点击区块工具栏 "注释" 图标
2. 添加注释内容（如："待审核"、"需要修改"）
3. 团队成员可在 "列表视图" 中查看所有注释
4. 解决后标记为 "已完成"
```

**适用场景：**
- 团队协作编辑
- 内容审核流程
- 设计反馈收集
- 修改意见传达

**3. 字体库管理**

**原理：** WordPress 7.0 提供独立的字体库管理页面，集中上传、安装和管理字体。

**使用方法：**
```
仪表盘 → 外观 → 字体库
1. 上传字体文件（.ttf、.otf、.woff、.woff2）
2. 设置字体变体（字重、样式）
3. 在 theme.json 或编辑器中使用
```

**theme.json 配置字体：**
```json
{
  "settings": {
    "typography": {
      "fontFamilies": [
        {
          "slug": "custom-font",
          "name": "自定义字体",
          "fontFamily": "CustomFont, sans-serif",
          "fontFace": [
            {
              "fontFamily": "CustomFont",
              "src": ["file:./assets/fonts/customfont.woff2"],
              "fontWeight": "400",
              "fontStyle": "normal"
            }
          ]
        }
      ]
    }
  }
}
```

**4. 响应式编辑增强**

**原理：** WordPress 7.0 允许在编辑器中直接控制区块在桌面端或移动端的显示/隐藏。

**使用方法：**
```
1. 选择区块 → 右侧设置面板
2. 找到 "响应式" 选项
3. 设置显示规则：
   - 桌面端：显示/隐藏
   - 平板端：显示/隐藏
   - 移动端：显示/隐藏
```

**5. 区块级自定义 CSS**

**原理：** 直接在编辑流程中控制单个区块样式，无需修改主题文件。

**使用方法：**
```
1. 选择区块 → 右侧设置面板 → "高级"
2. 在 "自定义 CSS" 中输入样式
3. 实时预览效果
```

**示例：**
```css
/* 添加阴影效果 */
box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);

/* 添加边框 */
border: 2px solid #1a73e8;
border-radius: 8px;

/* 添加过渡动画 */
transition: transform 0.3s ease;
```

### 实战：创建自定义页面模板

**需求：创建一个全宽页面模板**

**Step 1：创建模板文件**
```
在主题目录创建 page-fullwidth.php
```

**Step 2：编写模板代码**
```php
<?php
/**
 * Template Name: 全宽页面
 * Description: 没有侧边栏的全宽页面
 */

get_header();
?>

<div id="primary" class="content-area fullwidth">
    <main id="main" class="site-main" role="main">
    
        <?php while ( have_posts() ) : the_post(); ?>
        
            <article id="post-<?php the_ID(); ?>" <?php post_class(); ?>>
                <header class="entry-header">
                    <?php the_title( '<h1 class="entry-title">', '</h1>' ); ?>
                </header>
                
                <div class="entry-content">
                    <?php the_content(); ?>
                    <?php
                    wp_link_pages( array(
                        'before' => '<div class="page-links">' . __( 'Pages:', 'your-theme' ),
                        'after'  => '</div>',
                    ) );
                    ?>
                </div>
                
                <?php if ( comments_open() || get_comments_number() ) : ?>
                    <?php comments_template(); ?>
                <?php endif; ?>
                
            </article>
            
        <?php endwhile; ?>
        
    </main>
</div>

<?php get_footer(); ?>
```

**Step 3：添加样式**
```css
.content-area.fullwidth {
    width: 100%;
    max-width: 1200px;
    margin: 0 auto;
    padding: 40px 20px;
}
```

**Step 4：使用模板**
```
页面编辑 → 页面属性 → 模板 → 选择「全宽页面」
```

### 实战：注册自定义文章类型

**原理：** 自定义文章类型允许创建除文章和页面之外的内容类型。

**Step 1：在 functions.php 中注册**
```php
function create_portfolio_post_type() {
    // 标签定义
    $labels = array(
        'name'               => __( '作品集', 'text-domain' ),
        'singular_name'      => __( '作品', 'text-domain' ),
        'menu_name'          => __( '作品集', 'text-domain' ),
        'name_admin_bar'     => __( '作品', 'text-domain' ),
        'add_new'            => __( '添加作品', 'text-domain' ),
        'add_new_item'       => __( '添加新作品', 'text-domain' ),
        'new_item'           => __( '新作品', 'text-domain' ),
        'edit_item'          => __( '编辑作品', 'text-domain' ),
        'view_item'          => __( '查看作品', 'text-domain' ),
        'all_items'          => __( '所有作品', 'text-domain' ),
        'search_items'       => __( '搜索作品', 'text-domain' ),
        'parent_item_colon'  => __( '父作品:', 'text-domain' ),
        'not_found'          => __( '没有找到作品.', 'text-domain' ),
        'not_found_in_trash' => __( '回收站中没有作品.', 'text-domain' )
    );
    
    // 参数配置
    $args = array(
        'labels'             => $labels,
        'public'             => true,
        'publicly_queryable' => true,
        'show_ui'            => true,
        'show_in_menu'       => true,
        'query_var'          => true,
        'rewrite'            => array( 'slug' => 'portfolio' ),
        'capability_type'    => 'post',
        'has_archive'        => true,
        'hierarchical'       => false,
        'menu_position'      => 5,
        'menu_icon'          => 'dashicons-portfolio',
        'supports'           => array( 'title', 'editor', 'thumbnail', 'excerpt', 'custom-fields' )
    );
    
    register_post_type( 'portfolio', $args );
}
add_action( 'init', 'create_portfolio_post_type' );
```

**参数说明：**

| 参数 | 说明 |
|-----|-----|
| `public` | 是否公开可见 |
| `has_archive` | 是否启用归档页 |
| `rewrite` | URL 重写规则 |
| `supports` | 支持的功能（标题、编辑器等） |
| `menu_icon` | 菜单图标 |

**Step 2：创建归档模板**
```
创建 archive-portfolio.php
```

```php
<?php get_header(); ?>

<div id="primary" class="content-area">
    <main id="main" class="site-main" role="main">
    
        <header class="page-header">
            <h1 class="page-title"><?php post_type_archive_title(); ?></h1>
        </header>
        
        <?php if ( have_posts() ) : ?>
        
            <div class="portfolio-grid">
                <?php while ( have_posts() ) : the_post(); ?>
                
                    <article id="post-<?php the_ID(); ?>" <?php post_class( 'portfolio-item' ); ?>>
                        <?php if ( has_post_thumbnail() ) : ?>
                            <div class="portfolio-thumbnail">
                                <a href="<?php the_permalink(); ?>">
                                    <?php the_post_thumbnail( 'medium' ); ?>
                                </a>
                            </div>
                        <?php endif; ?>
                        
                        <header class="entry-header">
                            <?php the_title( '<h2 class="entry-title"><a href="' . esc_url( get_permalink() ) . '">', '</a></h2>' ); ?>
                        </header>
                        
                        <div class="entry-summary">
                            <?php the_excerpt(); ?>
                        </div>
                    </article>
                    
                <?php endwhile; ?>
            </div>
            
            <?php the_posts_navigation(); ?>
            
        <?php else : ?>
            <?php get_template_part( 'template-parts/content', 'none' ); ?>
        <?php endif; ?>
        
    </main>
</div>

<?php get_sidebar(); ?>
<?php get_footer(); ?>
```

### 实战：自定义字段（Advanced Custom Fields）

**原理：** 自定义字段允许在文章/页面中添加额外的元数据。

**Step 1：安装 ACF 插件**
```
插件 → 添加新插件 → 搜索 "Advanced Custom Fields" → 安装 → 启用
```

**Step 2：创建字段组**
```
自定义字段 → 添加新字段组
名称：作品信息
```

**Step 3：添加字段**

| 字段名 | 类型 | 说明 |
|-----|-----|-----|
| 作品年份 | 数字 | 作品创作年份 |
| 客户名称 | 文本 | 客户名称 |
| 项目链接 | URL | 项目演示链接 |

**Step 4：设置显示位置**
```
规则：显示在 作品类型 == portfolio
```

**Step 5：在模板中调用**
```php
<?php
// 显示作品年份
echo '<p>年份：' . get_field('作品年份') . '</p>';

// 显示客户名称
echo '<p>客户：' . get_field('客户名称') . '</p>';

// 显示项目链接
$link = get_field('项目链接');
if ( $link ) {
    echo '<a href="' . esc_url($link) . '" target="_blank">查看项目</a>';
}
?>
```

### 主题函数文件详解

**functions.php 是主题的核心文件，用于添加功能。**

**1. 启用主题支持**
```php
function mytheme_setup() {
    // 启用特色图片支持
    add_theme_support( 'post-thumbnails' );
    
    // 启用标题标签
    add_theme_support( 'title-tag' );
    
    // 启用 HTML5 支持
    add_theme_support( 'html5', array( 'search-form', 'comment-form', 'comment-list', 'gallery', 'caption' ) );
    
    // 启用自定义背景
    add_theme_support( 'custom-background', apply_filters( 'mytheme_custom_background_args', array(
        'default-color' => 'ffffff',
        'default-image' => '',
    ) ) );
}
add_action( 'after_setup_theme', 'mytheme_setup' );
```

**2. 注册菜单**
```php
function mytheme_register_nav_menus() {
    register_nav_menus( array(
        'primary' => __( '主菜单', 'mytheme' ),
        'secondary' => __( '二级菜单', 'mytheme' ),
        'footer' => __( '页脚菜单', 'mytheme' ),
    ) );
}
add_action( 'init', 'mytheme_register_nav_menus' );
```

**3. 注册侧边栏**
```php
function mytheme_widgets_init() {
    register_sidebar( array(
        'name'          => __( '侧边栏', 'mytheme' ),
        'id'            => 'sidebar-1',
        'description'   => __( '添加小工具到侧边栏', 'mytheme' ),
        'before_widget' => '<aside id="%1$s" class="widget %2$s">',
        'after_widget'  => '</aside>',
        'before_title'  => '<h2 class="widget-title">',
        'after_title'   => '</h2>',
    ) );
    
    register_sidebar( array(
        'name'          => __( '页脚小工具区', 'mytheme' ),
        'id'            => 'footer-1',
        'description'   => __( '添加小工具到页脚', 'mytheme' ),
        'before_widget' => '<div id="%1$s" class="widget %2$s">',
        'after_widget'  => '</div>',
        'before_title'  => '<h3 class="widget-title">',
        'after_title'   => '</h3>',
    ) );
}
add_action( 'widgets_init', 'mytheme_widgets_init' );
```

### 响应式设计原理

**原理：使用 CSS 媒体查询根据屏幕尺寸应用不同样式。**

**媒体查询示例：**
```css
/* 默认样式（桌面端） */
.container {
    width: 1200px;
    margin: 0 auto;
}

/* 平板端（768px - 991px） */
@media (max-width: 991px) {
    .container {
        width: 95%;
        padding: 0 15px;
    }
}

/* 手机端（最大767px） */
@media (max-width: 767px) {
    .container {
        width: 100%;
        padding: 0 10px;
    }
    
    /* 移动端菜单 */
    .main-navigation {
        display: none;
    }
    
    .mobile-menu-toggle {
        display: block;
    }
}

/* 大屏幕（最小1200px） */
@media (min-width: 1200px) {
    .container {
        width: 1170px;
    }
}
```
